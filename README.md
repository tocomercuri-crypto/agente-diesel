# Agente Diesel — Bicos Common Rail Bosch

Assistente técnico especializado em regulagem de bicos injetores diesel Common Rail Bosch.

## Funcionalidades

- Consulta sobre calibração dos 5 calços (DNH, RLS, DFK, MFK, AH/Gap)
- Diagnóstico de problemas comuns em injetores
- Dados de referência por Part Number (indutância, aplicação por veículo)
- Procedimentos técnicos de bancada
